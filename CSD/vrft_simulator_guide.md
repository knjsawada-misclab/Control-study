# VRFT によるデータ駆動型 PID ゲイン調整シミュレータ

制御系設計論 (大学院 機械工学専攻) ／大阪大学 澤田賢治

講義「⑦ 位相進み遅れ補償」の補足で扱った **VRFT (Virtual Reference Feedback Tuning)** を，ブラウザ上で手を動かして確認するシミュレータです．FRIT と同じく初期ゲインで得た 1 組の実験データ $(u_0, y_0)$ だけから PID ゲインを求めますが，VRFT は**開ループ系 $L(\rho) = PK(\rho)$ を規範開ループ $L_d$ に近づける**こと，評価関数がゲインについて線形で**反復なしの最小二乗で解ける**ことが特徴です．講義の MATLAB 例をそのまま再現できます．

> **対象**：微分フィルタ付き PID 制御器 $K(\rho)$ ， $\rho = [k_P, k_I, k_D]$ ，規範閉ループ $M(s) = 1/(T_m s + 1)^n$ ，規範開ループ $L_d = M/(1 - M)$ です．FRIT は別のシミュレータ `frit_simulator.html` で扱います．

付属の `vrft_simulator.html` を **ブラウザで開くだけ**で動作します (外部ライブラリ不要・オフライン可)．

```bash
git clone https://github.com/knjsawada-misclab/Control-study.git
cd Control-study/CSD

```

操作のポイント：

- **講義のプリセット** に講義の MATLAB 例 ( $P(s) = (12s+8)/(20s^4+113s^3+147s^2+63s+8)$ ， $M = 1/(0.5s+1)^2$ ， $\rho_0 = [3, 0.5, 0]$ ) を用意しています．
- **ステップ 1**「初期実験」で $\rho_0$ の閉ループ実験データ $(u_0, y_0)$ を取得します (シミュレータでは $P(s)$ で代替)．
- **ステップ 2, 3**「VRFT で ρ を求める」で，フィルタ後の回帰信号から非負最小二乗 (MATLAB の `lsqnonneg` 相当) で $\rho_1$ を一度に求めます．
- 左上の **一巡伝達関数の比較** で，調整後の $L_1$ が目標 $L_d$ に重なることを確認できます (講義の MATLAB 実行例の図)．
- 左下の **最小二乗の当てはめ** で，目標 $F u_0$ と回帰 $\Phi\rho$ の一致を確認できます．

## VRFT の手順

1. 初期ゲイン $\rho_0$ で実験し， $u_0$ ， $y_0$ を得る．
2. 規範閉ループ $M = L_d/(1 + L_d)$ を使って**仮想参照信号**と**仮想偏差**を作る．

```math
r_v = M^{-1} y_0, \qquad e_v = r_v - y_0 = (M^{-1} - 1)\,y_0
```

3. 評価関数を最小化する $\rho$ を求める．

```math
J_v(\rho) = \sum_{k=0}^{N-1} \varepsilon_v[k]^2, \qquad \varepsilon_v = u_0 - K(\rho)\,e_v
```

### なぜ開ループ系が規範に近づくのか

$u_0 = y_0/P$ であることと $e_v = y_0/L_d$ であることから

```math
\varepsilon_v = u_0 - K(\rho)\frac{y_0}{L_d} = \left(1 - \frac{PK(\rho)}{L_d}\right)u_0 = \left(1 - \frac{L(\rho)}{L_d}\right)u_0
```

となり，評価関数を最小化するゲインは $L(\rho) = L_d$ を達成します．

### FRIT との違い

| | FRIT | VRFT |
|:--|:--|:--|
| 疑似/仮想信号 | $\tilde r = K^{-1}u_0 + y_0$ | $r_v = M^{-1} y_0$ |
| 評価誤差 | $y_0 - M\tilde r(\rho)$ (出力の差) | $u_0 - K(\rho)e_v$ (制御器出力と実験入力の差) |
| 近づける対象 | 閉ループ系 $G_{yr} \to M$ | 開ループ系 $L \to L_d$ |
| 最適化 | $\rho$ について非線形 (反復) | $\rho$ について線形 (最小二乗 1 回) |

---

## 実装：ローパスフィルタと回帰

$M^{-1}$ は非プロパーなので $r_v$ をそのまま時間応答計算することはできません．講義と同じく $F = M$ でフィルタし，

```math
F e_v = (1 - M)\,y_0, \qquad F u_0 = M u_0
```

を計算します．PID 制御器は

```math
K(\rho) = k_P + \frac{k_I}{s} + k_D\frac{s}{\tau s + 1} = \rho^\top \begin{bmatrix} 1 \\ 1/s \\ s/(\tau s + 1) \end{bmatrix}
```

とゲインについて線形なので，回帰行列

```math
\Phi = \begin{bmatrix} (1 - M)y_0 & \dfrac{1 - M}{s}y_0 & \dfrac{s}{\tau s + 1}(1 - M)y_0 \end{bmatrix}
```

を作れば $J_v = \Vert F u_0 - \Phi\rho \Vert^2$ となり，非負制約付き最小二乗で解けます．シミュレータでは 3 変数の非負最小二乗を，自由変数の部分集合をすべて列挙して解く方法で厳密に求めています．

調整後の閉ループ安定性は VRFT では保証されないので，結果欄で $P(s)$ を使って別途確認しています．

### 講義の例での結果

$\rho_1 \approx [6.24, 0.99, 6.93]$ となり，調整後の一巡伝達関数 $L_1$ は $L_d$ にほぼ重なります．これは FRIT で得られる解とほぼ同じで，調整後の出力 $y_1$ は規範応答 $y_d = Mr$ に重なります．

---

## 数値計算の方法

- 時間応答は伝達関数を双一次変換 (Tustin 変換) で離散化し，IIR フィルタとして計算しています．
- 周波数応答は $s = j\omega$ を直接代入して計算し，ゲイン余裕・位相余裕は対数周波数グリッド上で求めています．
