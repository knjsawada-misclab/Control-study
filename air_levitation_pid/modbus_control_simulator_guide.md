# Modbus/TCP 制御通信シミュレータ

機械情報システム入門 (学問の扉) ／大阪大学 澤田賢治

空気浮上系における **Modbus/TCP 通信**をリアルタイムで可視化し，**DoS 攻撃・Replay 攻撃**が制御に与える影響を体験できるシミュレータです．HMI と PLC 間の通信，PID 制御グラフ，Modbus パケットログを同時に確認できます．

> **対象**：制御システムの通信構造 (HMI⇔PLC)，Modbus/TCP のファンクションコード (FC03/FC06)，サイバー攻撃が制御に与える物理的影響を体験的に学ぶシミュレータです．

---

## デモ / 使い方

付属の `modbus_control_simulator.html` を **ブラウザで開くだけ**で動作します (外部ライブラリ不要・オフライン可)．

操作のポイント：

- **▶ シミュレーション開始** で HMI⇔PLC 間の Modbus/TCP 通信がリアルタイムで動作開始．
- **SP 入力欄** で目標値を変更すると，FC06 (Write Single Register) が送信され，PID 制御が追従．
- **PID 制御グラフ** で SP (青破線)・PV (赤実線)・MV (橙実線) の変化をリアルタイム確認．
- **Modbus パケットログ** に FC03/FC06 の送受信がWireshark風に表示される．
- **攻撃モード** で DoS 攻撃・Replay 攻撃を選択し，制御への影響を体験．
- **速度** を 1x / 2x / 5x で調整可能．

---

## システム構成

空気浮上教育キットのネットワーク構成を再現しています．

- **HMI** (ScadaBR, 192.168.1.10)：監視・操作画面．Modbus/TCP のマスタ
- **PLC** (OpenPLC, 192.168.1.195:502)：PID 制御を実行．Modbus/TCP のスレーブ
- **センサ＋ブロワ**：PLC の I/O に接続．赤外線距離センサと DC ファン
- **Attacker**：攻撃モード有効時にネットワーク上に出現

## Modbus/TCP 通信の流れ

### 正常時

1. HMI が FC03 (Read Holding Registers) でレジスタ 0 番地から 3 個を読み取り
2. PLC が SP・PV・MV の値を返す
3. HMI がグラフに描画
4. 500ms 周期でステップ 1-3 を繰り返し (ポーリング)
5. SP 変更時：HMI が FC06 (Write Single Register) で新しい SP を書き込み

### パケットログの見方

| 色 | 意味 |
|---|---|
| 青 | FC03 読み取り (通常のポーリング) |
| 緑 | FC06 書き込み (SP 変更) |
| 赤 | 攻撃パケットまたはタイムアウト |

## 攻撃シミュレーション

### DoS 攻撃 (サービス妨害)

攻撃者が大量の TCP SYN パケットを送信し，ネットワークを輻輳させます．

- PLC の応答が遅延し，一部の FC03 読み取りがタイムアウト
- HMI のグラフが更新されなくなる (PV が凍結)
- PLC 内部の PID 制御は継続するが，HMI からは状態が見えない
- システム構成図の背景が赤く点滅

### Replay 攻撃 (再送攻撃)

攻撃者が過去に盗聴した FC06 パケット (SP=0) を再送します．

- SP が突然 0 に書き換えられる
- ファン出力 (MV) が急低下し，ピンポン球が落下
- パケットログに赤色の「Replay」タグ付きパケットが表示
- PV グラフが急激に低下する様子が可視化される

### セキュリティの教訓

Modbus/TCP には**認証も暗号化もない**ため：

- 同一ネットワーク上の誰でも FC06 でレジスタを書き換えられる
- パケットを盗聴してそのまま再送 (Replay) できる
- 対策：ネットワーク分離，ファイアウォール，通信の暗号化 (TLS)，異常検知

## PID 制御の仕組み

本シミュレータでは簡易な P 制御を使用しています．

- 誤差 e = SP - PV
- MV = Kp × e × 300 + ベースライン
- PV は MV に応じて1次遅れで追従 (+ ノイズ)

実際の空気浮上キットでは OpenPLC の PID ブロック (Kp, TD, TR パラメータ) を使用しています．
