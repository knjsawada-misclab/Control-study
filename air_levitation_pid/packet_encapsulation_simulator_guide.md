# パケットカプセル化シミュレータ

機械情報システム入門 (学問の扉) ／大阪大学 澤田賢治

TCP/IP 通信における**パケットのカプセル化** (封筒の入れ子) をアニメーションで可視化するシミュレータです．アプリケーションデータに各層のヘッダが順に付加される様子をインタラクティブに確認できます．

> **対象**：OSI 参照モデル・TCP/IP 階層モデルにおけるカプセル化 (Encapsulation) の仕組みを，HTTP・SMTP・Modbus/TCP・DHCP の具体例で体験的に学ぶシミュレータです．

---

## デモ / 使い方

付属の `packet_encapsulation_simulator.html` を **ブラウザで開くだけ**で動作します (外部ライブラリ不要・オフライン可)．

操作のポイント：

- **プロトコル選択** で HTTP / SMTP / Modbus/TCP / DHCP を切り替え．
- **▶ カプセル化** ボタンで，アプリケーションデータ (L7) → TCP/UDP (L4) → IP (L3) → Ethernet (L2) の順にヘッダが付加されるアニメーションを再生．
- **◀ デカプセル化** ボタンで，受信側の処理 (外側からヘッダを外す) を再生．
- 各層の**色つき枠をクリック**すると，ヘッダフィールドの詳細 (バイト数・具体的な値) が下部に表示される．
- **速度スライダー** でアニメーション速度を調整可能．

## カプセル化とは

### 封筒の入れ子

送信側では，上の層から順にヘッダ (制御情報) を付け加えながら下の層にデータを渡します．受信側では，下の層から順にヘッダを外しながら上の層にデータを渡します (デカプセル化)．

各層は自分のヘッダだけを読み，中のデータには手を付けません．この仕組みにより，層ごとの独立性が保たれます．

### 各層の役割

| 層 | 色 | 役割 | 付加される情報 |
|---|---|---|---|
| L7 アプリケーション | 赤 | ユーザーが使うサービス | HTTP/SMTP/Modbus コマンド |
| L4 トランスポート | 緑 (TCP) / 橙 (UDP) | 端末間の信頼性・サービス識別 | 送信元/宛先ポート番号，シーケンス番号 |
| L3 ネットワーク | 青 | ネットワーク間の経路選択 | 送信元/宛先 IP アドレス，TTL |
| L2 データリンク | 灰 | 同一 LAN 内の直接通信 | 送信元/宛先 MAC アドレス，FCS |

## プロトコル別の具体例

### HTTP (Web 閲覧)

TCP ポート 80 を使用．`GET / HTTP/1.1` というリクエストが，TCP → IP → Ethernet のヘッダに包まれてサーバに届きます．

### SMTP (メール送信)

TCP ポート 25 を使用．`EHLO student.local` などの SMTP コマンドが同様にカプセル化されます．

### Modbus/TCP (制御通信)

TCP ポート 502 を使用．HMI (192.168.1.10) から PLC (192.168.1.195) への FC03 (Read Holding Registers) 要求がカプセル化される例を確認できます．MBAP ヘッダのフィールドも表示されます．

### DHCP (IP 自動取得)

UDP ポート 67/68 を使用．IP アドレスがまだない状態 (送信元 0.0.0.0) からブロードキャスト (宛先 255.255.255.255) で通信する特殊なケースを確認できます．

## Wireshark との対応

本シミュレータで確認できるカプセル化の構造は，Wireshark でパケットをキャプチャしたときに表示される階層構造と同じです．

- Wireshark の「パケット詳細」ペイン：Ethernet → IP → TCP → Application の順に展開
- 本シミュレータの入れ子構造：外側 (灰) → 青 → 緑 → 赤 の順に対応
