# 開ループ系の制御仕様：ナイキスト軌跡と余裕のシミュレータ

制御系設計論 (大学院 機械工学専攻) ／大阪大学 澤田賢治

講義「⑤ 開ループ系の制御仕様」の内容を，ブラウザ上で手を動かして確認するシミュレータです．開ループ伝達関数 $L(s) = kP(s)$ のループゲイン $k$ をスライダで動かすと，**ナイキスト軌跡・ボード線図・閉ループ系のゲイン特性・ステップ応答が同時に更新**され，開ループ系の仕様 (ゲイン交差角周波数 $\omega_{gc}$ ，位相交差角周波数 $\omega_{pc}$ ，位相余裕 PM，ゲイン余裕 GM) と閉ループ系の仕様 (ピークゲイン $M_p$ ，バンド幅 $\omega_{bw}$ ，定常偏差) の対応を観察できます．

> **対象**：任意の伝達関数 $P(s)$ (係数入力) に比例ゲイン $k$ をかけた一巡伝達関数 $L(s) = kP(s)$ と，その閉ループ系 $G_{yr}(s) = L(s)/(1 + L(s))$ です．

## デモ / 使い方

付属の `open_loop_spec_simulator.html` を **ブラウザで開くだけ**で動作します (外部ライブラリ不要・オフライン可)．

```bash
git clone https://github.com/knjsawada-misclab/Control-study.git
cd Control-study/CSD
start open_loop_spec_simulator.html     # Windows
```

操作のポイント：

- **講義のプリセット** で講義の問題 1・2 ( $L = 1/((s+1)(s+2)(s+3))$ ) と，その $k$ を 30，60 (安定限界)，100 (不安定) にした場合を呼び出せます．
- **ループゲイン k のスライダ** を動かすと，ナイキスト軌跡が $-1$ 点に近づき，通過し，囲む様子を連続的に確認できます (講義の図の A → B → C → D → E)．
- **ナイキスト軌跡** には単位円 (スモールゲイン定理の領域)， $\omega_{gc}$ の点と位相余裕の弧， $\omega_{pc}$ の点とゲイン余裕の線分を表示します．
- **ボード線図** には $\omega_{gc}$ での PM と $\omega_{pc}$ での GM を矢印で示します．
- **閉ループ系 |Gyr|** には $-3$ dB 線 (バンド幅) と，問題 3 の下界 $1/(2\sin(\mathrm{PM}/2))$ を表示します．

## 閉ループ系と開ループ系

閉ループ系の伝達関数は一巡伝達関数 $L(s) = P(s)K(s)$ で決まります．

```math
G_{yr}(s) = \frac{L(s)}{1 + L(s)}, \qquad G_{er}(s) = \frac{1}{1 + L(s)}
```

$L$ が定数のときは $y = Lr - L^2 r + L^3 r - \cdots$ が $|L| < 1$ で収束して $L/(1+L)$ になります．複素関数のときはゲイン $|L(j\omega)|$ と位相 $\angle L(j\omega)$ で収束特性が決まるので，開ループ系の周波数特性に注目することが自然になります．

### 仕様の対応関係

| 項目 | 閉ループ系 $G_{yr}$ | 開ループ系 $L$ |
|:--|:--|:--|
| 安定性 | 特性多項式の根が左半面 | ナイキストの安定判別法： $\omega_{pc} > \omega_{gc}$ |
| 減衰性 | ピークゲイン $M_p$ を小さく | 位相余裕 PM，ゲイン余裕 GM を大きく |
| 速応性 | バンド幅 $\omega_{bw}$ を大きく | ゲイン交差角周波数 $\omega_{gc}$ を大きく |
| 定常特性 | $G_{yr}(0) \to 1$ (直流ゲイン 0 dB) | 低周波ゲイン $\vert L(0) \vert$ を大きく |

---

## ナイキストの安定判別 (問題 1)

$L(s) = 1/((s+1)(s+2)(s+3))$ の周波数応答は

```math
L(j\omega) = \frac{1}{6(1 - \omega^2) + j\omega(11 - \omega^2)}
```

です．位相交差角周波数は虚部が 0 になる $\omega_{pc} = \sqrt{11}$ で，実軸交差点は $L(j\sqrt{11}) = -1/60$ です．軌跡が $-1$ を左に見て原点に収束するので閉ループ系は安定です．シミュレータの結果欄に $\omega_{pc} = 3.317$ ， $L(j\omega_{pc}) = -0.0167$ が表示されます．

### ゲイン余裕 (問題 2)

```math
\mathrm{GM} = \frac{1}{\vert L(j\omega_{pc}) \vert} = 60 \;\;(\approx 35.6\ \mathrm{dB})
```

したがって $k = 60$ で軌跡が $-1$ を通り安定限界， $k > 60$ で不安定になります．プリセット「k=60」「k=100」で確認できます．

### スモールゲイン定理

$|L(j\omega)| < 1$ がすべての $\omega$ で成り立てば，軌跡は単位円の内側にあるので必ず安定です．ナイキスト軌跡の単位円 (緑の領域) で確認できます．

---

## 位相余裕とピークゲイン (問題 3)

ゲイン交差角周波数では $|L(j\omega_{gc})| = 1$ なので

```math
\vert G_{yr}(j\omega_{gc}) \vert = \frac{1}{\vert 1 + L(j\omega_{gc}) \vert} = \frac{1}{2\sin(\mathrm{PM}/2)}
```

が成り立ち， $M_p = \max_\omega \vert G_{yr}(j\omega) \vert \ge 1/(2\sin(\mathrm{PM}/2))$ となります．位相余裕が小さいほどピークゲインの下界が大きくなります．閉ループ系のゲイン線図にこの下界を紫の破線で表示しています．

### バンド幅と速応性

$G_{yr}(0) = 1$ のとき， $\mathrm{PM} = 90°$ なら $\vert G_{yr}(j\omega_{gc}) \vert = 1/\sqrt{2}$ となって $\omega_{gc} = \omega_{bw}$ ， $\mathrm{PM} \le 90°$ なら $\omega_{gc} \le \omega_{bw}$ です．ゲイン交差角周波数を大きくすることがバンド幅を広げ，速応性を高めることに対応します．

### 定常特性

ステップ入力に対する定常偏差は

```math
e_\infty = G_{er}(0) = \frac{1}{1 + L(0)}
```

です．定常偏差を 0 にするには $L(0) \to \infty$ ，すなわち $K(s)$ に積分器が必要です．プリセット「P = 1/(s(s+1))」で積分器を含む場合を確認できます．

## 結果欄の見方

| 項目 | 意味 |
|:--|:--|
| $\omega_{gc}$ | $\vert L \vert = 1$ (0 dB) となる角周波数．「なし」は全域で $\vert L \vert < 1$ |
| $\omega_{pc}$ | $\angle L = -180°$ となる角周波数．「なし」は位相が $-180°$ に達しない |
| PM | $180° + \angle L(j\omega_{gc})$ |
| GM | $-20\log_{10} \vert L(j\omega_{pc}) \vert$ [dB] |
| $M_p$ | 閉ループ系のピークゲインと，そのときの角周波数 $\omega_p$ |
| 下界 | $1/(2\sin(\mathrm{PM}/2))$ |
| $\omega_{bw}$ | 直流ゲインから $-3$ dB になる角周波数 |
| 閉ループ極 | 特性多項式 $a(s) + k b(s)$ の根 |
