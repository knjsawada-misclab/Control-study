# 移動体の位置決め制御シミュレータ

制御工学 (応用理工学科機械工学科目3年) ／大阪大学 澤田賢治

移動体の位置決め制御を題材に，**s 平面上でのインタラクティブな極配置**による状態フィードバック制御の設計を体験するシミュレータです．極をドラッグ操作で配置すると，PD ゲインが自動算出され，車両アニメーションと時間応答がリアルタイムに更新されます．

> **対象**：二重積分器 $m\ddot{z} = u$ に対する PD 制御 $u = -k_p(z - z_r) - k_d\dot{z}$ のゲイン設計を，閉ループ極の位置から直感的に学ぶシミュレータです．

---

## デモ / 使い方

付属の `vehicle_positioning_simulator.html` を **ブラウザで開くだけ**で動作します (外部ライブラリ不要・オフライン可)．

```bash
git clone https://github.com/knjsawada-misclab/Control-study.git
cd Control-study/CNTENG
start vehicle_positioning_simulator.html     # Windows
```

操作のポイント：

- **s 平面上で極をドラッグ** して閉ループ極を配置 (最重要機能)．
- **極配置モード** を選択：共役複素極，実数2重根 (臨界減衰)，異なる実数根．
- **プリセットボタン** で Butterworth・臨界減衰・不足減衰を一発設定．
- 極の位置に応じて $\omega_n$ , $\zeta$ , $k_p$ , $k_d$ が自動算出．
- **車両アニメーション** で移動体が目標位置に向かう様子を確認．
- **時間応答** で $z(t)$ のオーバーシュート・整定時間を確認．

## 移動体の位置決め制御

### 運動方程式

質量 $m$ の移動体の運動方程式は

```math
m\ddot{z} = u
```

目標位置 $z_r$ への位置決めのため，PD 制御を適用します：

```math
u = -k_p(z - z_r) - k_d\dot{z}
```

### 状態方程式

偏差変数 $x_e = [z - z_r,\; \dot{z}]^\top$ を導入すると，

```math
\dot{x}_e = \begin{bmatrix} 0 & 1 \\ -k_p/m & -k_d/m \end{bmatrix} x_e
```

閉ループ系の特性多項式は

```math
s^2 + \frac{k_d}{m} s + \frac{k_p}{m} = s^2 + 2\zeta\omega_n s + \omega_n^2
```

### ゲインと極の関係

```math
k_p = \omega_n^2 m, \quad k_d = 2\zeta\omega_n m
```

極の位置 ($\sigma, \omega$) から $\omega_n = \sqrt{\sigma^2 + \omega^2}$ , $\zeta = -\sigma/\omega_n$ と計算されるため，s 平面上で極をドラッグするだけで制御ゲインが決定されます．

## インタラクティブな極配置

### 極配置モード

| モード | 説明 |
|---|---|
| 共役複素極 | 上側の極をドラッグすると下側が自動ミラー |
| 実数2重根 | 実軸上のみドラッグ可能，臨界減衰 |
| 異なる実数根 | 2つの実極を独立にドラッグ |

### s 平面の見方

- **緑の領域** (左半面)：安定領域
- **破線の円**： $\omega_n$ の等高線 (応答速度の指標)
- **放射線**： $\zeta$ の等高線 (減衰比の指標)
- 極を**原点から遠く** (大きな $\omega_n$ ) → 応答が速い
- 極を**実軸に近く** (大きな $\zeta$ ) → 振動が少ない

### 極の位置と応答の関係

- **実部** $\sigma < 0$ ： $|\sigma|$ が大きいほど収束が速い
- **虚部** $\omega$ ： $|\omega|$ が大きいほど振動的
- $\zeta = 1/\sqrt{2}$ (Butterworth)：実部と虚部が等しく，バランスが良い
- $\zeta = 1$ (臨界減衰)：振動なしで最速の非振動応答

## プリセット

| プリセット | $\zeta$ | $\omega_n$ | 特徴 |
|---|---|---|---|
| Butterworth | 0.707 | 3 | オーバーシュート約4%，速応性良好 |
| 臨界減衰 | 1.0 | 3 | オーバーシュートなし |
| 不足減衰 | 0.3 | 3 | 大きなオーバーシュート，振動的 |

## パラメータ一覧

### 入力パラメータ

| パラメータ | 説明 | 既定値 |
|---|---|---|
| $m$ | 質量 [kg] | $1$ |
| $z_r$ | 目標位置 [m] | $1.0$ |
| $z(0)$ | 初期位置 [m] | $0$ |
| $\dot{z}(0)$ | 初期速度 [m/s] | $0$ |
| 極配置モード | 共役複素 / 2重根 / 異なる実根 | 共役複素 |
| $T$ | シミュレーション時間 [s] | $5$ |

### 解析結果 (出力)

| 表示項目 | 説明 |
|---|---|
| $K = [k_p, k_d]$ | PD ゲイン (極配置から自動算出) |
| 閉ループ極 | ドラッグで配置した極の値 |
| $\omega_n$ , $\zeta$ | 固有角周波数と減衰比 |
| オーバーシュート | ステップ応答のオーバーシュート率 |
| 整定時間 | 2% 基準の整定時間 |
| 安定性 | 安定/不安定バッジ |

### プロット

| プロット | 内容 |
|---|---|
| s 平面 (インタラクティブ) | 極をドラッグで配置，$\omega_n$ 円と $\zeta$ 線を表示 |
| 車両アニメーション | 移動体が目標位置に移動する様子 |
| 時間応答 | $z(t)$ と目標値 $z_r$ ，整定帯を表示 |

### 数値計算手法

| 項目 | 手法 |
|---|---|
| 時間積分 | 4次 Runge-Kutta 法 (RK4) |
| ゲイン算出 | 極の位置から $\omega_n$ , $\zeta$ を算出し，係数比較 |
| アニメーション | requestAnimationFrame による描画 |
