ループ整形法：PID制御のボード線図

L(s) = P(s)K(s),   K(s) = kP + kI/s + kD s = k(1 + 1/(T1 s))(1 + T2 s)
講義図のプリセット
プリセットは比較トレースを自動で保持します．
制御対象 P(s) = b(s)/a(s)
PID 制御器 K(s)
kP = k(1 + T2/T1), kI = k/T1, kD = kT2．T1 = 0 は積分なし，T2 = 0 は微分なしとして扱います．
