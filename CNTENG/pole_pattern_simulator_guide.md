# 極配置パターン比較シミュレータ

制御工学 (応用理工学科機械工学科目3年) ／大阪大学 澤田賢治

アクティブ除振台の PD 制御を題材に，代表的な**極配置パターン** (Butterworth, 臨界減衰, Bessel 等) の応答特性の違いをインタラクティブに比較するシミュレータです．同じ固有角周波数 $\omega_n$ に対して減衰比 $\zeta$ を変えたときの振動抑制効果を，除振台アニメーション・時間応答・極配置図・性能指標バーチャートで同時に可視化します．

> **対象**：2次系の閉ループ特性多項式 $s^2 + 2\zeta\omega_n s + \omega_n^2 = 0$ における減衰比 $\zeta$ の選び方と過渡応答の関係を体験的に学ぶシミュレータです．

---

## デモ / 使い方

付属の `pole_pattern_simulator.html` を **ブラウザで開くだけ**で動作します (外部ライブラリ不要・オフライン可)．

```bash
git clone https://github.com/knjsawada-misclab/Control-study.git
cd Control-study/CNTENG
start pole_pattern_simulator.html     # Windows
```

操作のポイント：

- **物理パラメータ** (質量 $m$ , 減衰 $d$ , ばね定数 $k$ ) を編集．
- **固有角周波数** $\omega_n$ を設定 (応答速度の指標)．
- **極配置パターン** をチェックボックスで複数選択し，同時比較．
- **カスタム** パターンで任意の $\zeta$ を入力可能．
- **▶ 計算・比較** で全パターンを一括シミュレーションし，アニメーションを再生．
- **除振台アニメーション** で各パターンの振動抑制効果を視覚的に比較．再生/一時停止・速度調整が可能．

## アクティブ除振台

### 運動方程式

質量 $m$ がばね定数 $k$ と減衰係数 $d$ で支持された除振台の運動方程式は

```math
m\ddot{y}(t) + d\dot{y}(t) + ky(t) + u(t) = f(t)
```

ここで $y(t)$ は台の変位， $u(t)$ はアクチュエータ力 (PD 制御入力)， $f(t)$ は上方からの衝撃力です．

### PD 制御 (状態フィードバック)

```math
u(t) = c_p y(t) + c_d \dot{y}(t)
```

閉ループ系の特性多項式は

```math
s^2 + \frac{d + c_d}{m} s + \frac{k + c_p}{m} = s^2 + 2\zeta\omega_n s + \omega_n^2
```

所望の $\zeta$ と $\omega_n$ から PD ゲインが一意に定まります：

```math
c_d = 2\zeta\omega_n m - d, \quad c_p = \omega_n^2 m - k
```

$\omega_n$ が同じなら $c_p$ は全パターンで共通であり， $c_d$ のみが $\zeta$ に応じて変化します．

## 代表的な極配置パターン

### 2次系の閉ループ極

閉ループ特性多項式 $s^2 + 2\zeta\omega_n s + \omega_n^2 = 0$ の根は

```math
s = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^2 - 1}
```

$\zeta < 1$ のとき共役複素極 (振動的)， $\zeta = 1$ で重根 (臨界減衰)， $\zeta > 1$ で異なる実根 (過減衰) となります．

### パターン一覧

| パターン | $\zeta$ | 特徴 |
|---|---|---|
| **Butterworth** | $1/\sqrt{2} \approx 0.707$ | 振幅特性が最大限平坦．オーバーシュートと速応性のバランスが良い |
| **臨界減衰** (重根) | $1.0$ | 振動なしで最速の応答．オーバーシュートゼロ |
| **Bessel** | $\sqrt{3}/2 \approx 0.866$ | 群遅延特性が最大限平坦．波形歪みが少ない |
| **不足減衰** | $0.3$ | 大きなオーバーシュート，振動的な応答 |
| **過減衰** | $1.5$ | 振動なしだが応答が遅い |

### Butterworth 標準形

Butterworth パターンは s 平面上で極が虚軸からの角度 45° に配置されます．2次系では $\zeta = 1/\sqrt{2}$ であり，振幅特性のゲイン曲線が通過帯域で最も平坦になります．除振台の設計では，振動抑制と速応性のバランスが良く，広く採用されるパターンです．

### オーバーシュートと減衰比の関係

$\zeta < 1$ のとき，ステップ応答のオーバーシュート率は理論的に

```math
\mathrm{OS\%} = \exp\!\left(\frac{-\pi\zeta}{\sqrt{1-\zeta^2}}\right) \times 100
```

| $\zeta$ | OS% | 応答の特徴 |
|---|---|---|
| 0.3 | 37.2% | 大きな振動，整定が遅い |
| 0.5 | 16.3% | 振動あり |
| 0.707 | 4.3% | Butterworth，わずかな振動 |
| 0.866 | 0.6% | Bessel，ほぼ振動なし |
| 1.0 | 0% | 臨界減衰，振動なし |

### 設計のトレードオフ

- $\omega_n$ を大きくする → 応答が速くなるが，大きな制御ゲインが必要
- $\zeta$ を大きくする → オーバーシュートが減るが，立ち上がりが遅くなりうる
- Butterworth ($\zeta = 0.707$) は多くの工学応用で良いバランスを提供
- 除振台では**振動の抑制 (OS% が小さい)** と**速い整定 (整定時間が短い)** の両立が重要

## シミュレータの表示内容

### 除振台アニメーション

チェックしたパターンの除振台を並列に表示します．上方からの衝撃力 $f(t)$ に対して，各パターンの PD 制御がどの程度振動を抑制するかを視覚的に比較できます．

- 各パターンは固有の色で描画
- バネ・ダンパー・アクチュエータの動きが連動
- 再生/一時停止・速度調整 (0.5x〜2x) が可能

### 極配置図 (s 平面)

$\omega_n$ の円上に各パターンの極を色分けで表示します． $\zeta$ 線 (原点からの放射線) も描画され，極の位置と減衰比の関係が直感的にわかります．

### 時間応答

全パターンの $y(t)$ を同一グラフに重ねて表示します．定常値 $y_{ss}$ と $\pm 2\%$ 整定帯も表示され，各パターンの応答の違いを定量的に比較できます．

### 性能指標バーチャート

オーバーシュート (%) と整定時間 (s) を棒グラフで並列表示し，パターン間の性能差を一目で把握できます．

## パラメータ一覧

### 入力パラメータ

| パラメータ | 説明 | 既定値 |
|---|---|---|
| $m$ | 質量 [kg] | $1$ |
| $d$ | 減衰係数 [Ns/m] | $0.5$ |
| $k$ | ばね定数 [N/m] | $4$ |
| $\omega_n$ | 固有角周波数 [rad/s] | $3$ |
| パターン | チェックボックスで複数選択 | Butterworth, 臨界減衰 |
| 外乱 | インパルス / ステップ | ステップ |

### 解析結果 (出力)

| 表示項目 | 説明 |
|---|---|
| 比較テーブル | 各パターンの $\zeta$, 極, ゲイン, OS%, 整定時間 |
| 除振台アニメーション | 各パターンの振動抑制効果を並列表示 |
| 極配置図 | s 平面上の極の位置と $\zeta$ 線 |
| 時間応答 | 全パターンの $y(t)$ を重ねてプロット |
| 性能指標バーチャート | オーバーシュートと整定時間の棒グラフ比較 |

### 数値計算手法

| 項目 | 手法 |
|---|---|
| 時間積分 | 4次 Runge-Kutta 法 (RK4) |
| 整定時間 | 2% 基準 |
| オーバーシュート | ピーク値と定常値からの算出 |
| アニメーション | requestAnimationFrame による描画 |
