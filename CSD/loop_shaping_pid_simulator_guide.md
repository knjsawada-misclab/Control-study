# ループ整形法 (PID 制御) シミュレータ

制御系設計論 (大学院 機械工学専攻) ／大阪大学 澤田賢治

講義「⑥ ループ整形法 (PID 制御)」の内容を，ブラウザ上で手を動かして確認するシミュレータです．PID 制御器のゲイン $k_P$ ， $k_I$ ， $k_D$ を変えると，**制御器 $K(j\omega)$ と一巡伝達関数 $L(j\omega) = P(j\omega)K(j\omega)$ のボード線図**がどう変わり，低域 (定常特性)・中域 (安定性と過渡特性)・高域 (ロールオフ) の整形にどう効くかを観察できます．並列形と直列形の相互変換にも対応しています．

> **対象**：任意の伝達関数 $P(s)$ (係数入力) と PID 制御器 $K(s) = k_P + k_I/s + k_D s$ (近似微分付き) です．講義の図は $P(s) = 8/((s+2)(s+5))$ で描かれています．

## デモ / 使い方

付属の `loop_shaping_pid_simulator.html` を **ブラウザで開くだけ**で動作します (外部ライブラリ不要・オフライン可)．

```bash
git clone https://github.com/knjsawada-misclab/Control-study.git
cd Control-study/CSD
start loop_shaping_pid_simulator.html     # Windows
```

操作のポイント：

- **講義図のプリセット** で，P 制御 ( $k_P = 1, 2, 5$ )，PI 制御 ( $k_I = 0, 5, 10$ )，PID 制御 ( $k_D = 0, 0.2, 0.5$ ) の比較図を再現します．比較トレースが自動で保持されます．
- **並列形 / 直列形** のどちらで入力しても，もう一方のパラメータが自動計算されます．
- **$L = PK$ のボード線図** には $\omega_{gc}$ を中心とした低域・中域・高域の帯域を色分けし，PM と GM を矢印で示します．
- **$K$ のボード線図** には $1/T_I$ ， $1/T_D$ の折点を表示します．
- 「現在の結果を比較に保持」で任意のゲインの組み合わせを重ね描きできます (最大 4 本)．

## ループ整形の考え方

閉ループ系 $G_{yr} = PK/(1 + PK)$ では，制御対象やゲインの定数倍変化が閉ループ系の定数倍変化として現れません．一方，一巡伝達関数 $L = PK$ ではゲインの変化がそのまま $|L|$ の上下として現れるので，**ボード線図を見ながら $L$ の形を整える**ことで設計の見通しが良くなります．

### 周波数帯域ごとの役割

| 帯域 | 役割 | 目安 |
|:--|:--|:--|
| 低域 ( $\omega \ll \omega_{gc}$ ) | 定常特性 | ステップ追従: $-20$ dB/dec，ランプ追従: $-40$ dB/dec |
| 中域 ( $\omega_{gc}$ 付近) | 安定性と過渡特性 | $-20$ dB/dec 程度で 0 dB を横切る， $\omega_{gc}$ を高く，PM を確保 |
| 高域 ( $\omega \gg \omega_{gc}$ ) | ロールオフ (耐ノイズ性) | $-40$ 〜 $-60$ dB/dec |

経験的な設定値：追従制御では PM = 40° 〜 60°，GM = 10 〜 20 dB，定値制御では PM ≥ 20°，GM = 3 〜 10 dB．

## P, PI, PD, PID 制御のボード線図

### P 制御： $K = k_P$

$|L|$ 全体が $k_P$ 倍 (dB では上下に平行移動) されます． $k_P$ を大きくすると低周波ゲインが上がって定常偏差が小さくなり， $\omega_{gc}$ が高くなって速応性が上がりますが，PM が減って振動的になります．

### PI 制御： $K = k_P + k_I/s = k_P (1 + 1/(T_I s))$ ， $T_I = k_P/k_I$ (積分時間)

$1/T_I$ より低い周波数で $|K|$ が $-20$ dB/dec で立ち上がり，位相が $-90°$ に近づきます．低周波ゲインが大きくなって (積分器なので $|L(0)| = \infty$ ) 定常偏差が 0 になります． $1/T_I \ll \omega_{gc}$ であれば $\omega_{gc}$ 付近への影響は小さく，速応性・減衰性はあまり変わりません． $1/T_I$ が $\omega_{gc}$ に近いと位相遅れが PM を減らし，減衰性が劣化します．

### PD 制御： $K = k_P + k_D s = k_P (1 + T_D s)$ ， $T_D = k_D/k_P$ (微分時間)

$1/T_D$ より高い周波数で $|K|$ が $+20$ dB/dec で増え，位相が $+90°$ に近づきます． $1/T_D$ を $\omega_{gc}$ 付近に置くと位相進みで PM が増え，速応性・減衰性が改善されます．低周波の特性は変わらないので定常偏差は変わりません．高周波ゲインが大きくなるので耐ノイズ性は劣化します．

### PID 制御の直列補償表現

並列形の PID は

```math
K(s) = k_P + \frac{k_I}{s} + k_D s = k\left(1 + \frac{1}{T_1 s}\right)(1 + T_2 s)
```

と直列形に書き換えられ，

```math
k_P = k\left(1 + \frac{T_2}{T_1}\right), \qquad k_I = \frac{k}{T_1}, \qquad k_D = k T_2
```

の関係があります．直列形ではボード線図上で $1/T_1$ 以下が PI の効果， $1/T_2$ 以上が PD の効果と分離して見えるので，各パラメータの影響がわかりやすくなります．逆変換は $T_1$ ， $T_2$ を $x^2 - (k_P/k_I)x + k_D/k_I = 0$ の根として求めます ( $k_P^2 < 4 k_I k_D$ のときは実数化できません)．

## 講義の問題：位相余裕の計算

$P(s) = 1/(s+10)^4$ ， $K = k_P$ のとき

```math
\vert L(j\omega) \vert = \frac{k_P}{(100 + \omega^2)^2} = 1 \;\Rightarrow\; \omega_{gc} = \sqrt{\sqrt{k_P} - 100}, \qquad
\mathrm{PM} = 180° - 4\tan^{-1}\frac{\omega_{gc}}{10}
```

プリセット「P = 1/(s+10)^4」では $k_P = 5000, 20000, 40000$ を比較します． $k_P = 20000$ で $\omega_{gc} = 6.44$ ，PM = 48.9°， $k_P = 40000$ で PM = 0° (安定限界) になることが確認できます．

## 結果欄の見方

| 項目 | 意味 |
|:--|:--|
| $\omega_{gc}$ ， PM | ゲイン交差角周波数と位相余裕 |
| $\omega_{pc}$ ， GM | 位相交差角周波数とゲイン余裕 |
| 低周波ゲイン | $\vert L(0) \vert$ ．積分器があれば ∞ |
| ステップ定常偏差 | $1/(1 + L(0))$ |
| 低域・高域の傾き | 0.01 → 0.1 rad/s，10 → 100 rad/s での $\vert L \vert$ の変化 [dB/dec] |
| $T_I$ ， $T_D$ | 積分時間，微分時間とその折点周波数 |
| 直列形 $k, T_1, T_2$ | 並列形からの変換結果 |
| $M_p$ ， $\omega_{bw}$ | 閉ループ系のピークゲインとバンド幅 |

## パラメータ一覧

| パラメータ | 初期値 | 説明 |
|:--|:--|:--|
| 分子係数 / 分母係数 | `8` / `1 7 10` | $P(s) = 8/((s+2)(s+5))$ |
| $k_P$ ， $k_I$ ， $k_D$ | 1, 0, 0 | 並列形のゲイン |

| 近似微分の時定数 $\tau$ | 0.001 s | $k_D s \to k_D s/(\tau s + 1)$ |
| 終了時刻 T | 5 s | ステップ応答の計算 |
