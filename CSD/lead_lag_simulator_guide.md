# 位相進み遅れ補償シミュレータ

制御系設計論 (大学院 機械工学専攻) ／大阪大学 澤田賢治

講義「⑦ 位相進み遅れ補償」の内容を，ブラウザ上で手を動かして確認するシミュレータです．直列補償器

```math
K(s) = k \cdot \alpha\frac{T_1 s + 1}{\alpha T_1 s + 1} \cdot \frac{T_2 s + 1}{\beta T_2 s + 1}, \qquad \alpha > 1,\; \beta < 1
```

(ゲイン補償 × 位相遅れ補償 × 位相進み補償) のパラメータを変えながら，ボード線図上で $L = PK$ を整形し，ランプ応答の定常偏差・位相余裕・速応性がどう変わるかを観察できます．講義の例 1 〜 例 3 ( $P(s) = 8/(s(s+2))$ ) をプリセットで再現し，講義の設計手順を実行する「設計補助」ボタンも用意しています．

> **対象**：任意の伝達関数 $P(s)$ (係数入力) と，位相遅れ補償器・位相進み補償器の直列接続です．

---

## デモ / 使い方

付属の `lead_lag_simulator.html` を **ブラウザで開くだけ**で動作します (外部ライブラリ不要・オフライン可)．

```bash
git clone https://github.com/knjsawada-misclab/Control-study.git
cd Control-study/CSD
start lead_lag_simulator.html     # Windows
```

操作のポイント：

- **講義のプリセット**：補償なし，例 1 (位相遅れ $\alpha = 10$ ， $T_1 = 5, 2, 1$ の比較)，例 2 (位相進み $\phi_m = 30°$ )，例 3 (進み + 遅れ)．
- **位相遅れ補償 / 位相進み補償** のチェックで各補償器の有無を切り替え， $\alpha, T_1$ ， $\beta, T_2$ を入力します．
- **設計補助**：「T1 を決める」は現在の $L$ の $\omega_{gc}$ から $1/T_1 = \omega_{gc}/(\text{比})$ で $T_1$ を決めます．「β, T2 を決める」は $\phi_m$ から $\beta$ を計算し， $\vert L(j\omega_m) \vert = \sqrt{\beta}$ となる $\omega_m$ から $T_2 = 1/(\omega_m\sqrt{\beta})$ を決めます．
- 右下の **時間応答** はプルダウンでランプ偏差 $e(t) = r - y$ ，ランプ応答，ステップ応答を切り替えられます．

## 位相遅れ補償

```math
K_{lag}(s) = \alpha\frac{T_1 s + 1}{\alpha T_1 s + 1} \quad (\alpha > 1)
```

低周波のゲインを $\alpha$ 倍 ( $20\log_{10}\alpha$ dB) に上げ，高周波のゲインは変えません．位相は $1/(\alpha T_1)$ と $1/T_1$ の間で遅れ，最大遅れは

```math
\omega_m = \frac{1}{T_1\sqrt{\alpha}}, \qquad \phi_m = \sin^{-1}\frac{1 - \alpha}{1 + \alpha}
```

です．位相遅れが $\omega_{gc}$ に影響しないように， $1/T_1$ を $\omega_{gc}$ の 1/10 以下に置くのが設計指針です．

### 例 1：ランプ応答の定常偏差を 1/10 にする

$P(s) = 8/(s(s+2))$ のランプ応答の定常偏差は

```math
e_\infty = \lim_{s \to 0}\frac{1}{s L(s)} = \frac{1}{K_v}, \qquad K_v = \lim_{s\to 0} sL(s)
```

で， $K = 1$ のとき $K_v = 4$ ， $e_\infty = 1/4$ です．位相遅れ補償を入れると $K_v$ が $\alpha$ 倍になるので $\alpha = 10$ で $e_\infty = 1/40$ になります． $\omega_{gc} = \sqrt{-2 + 2\sqrt{17}} \approx 2.499$ から $1/T_1 < 0.25$ ，例えば $T_1 = 5$ とします．

プリセット「例 1」では $T_1 = 5, 2, 1$ を比較します． $T_1 = 5$ は設計指針どおりで位相余裕 34.5° ， $T_1 = 1$ では $1/T_1$ が $\omega_{gc}$ に近いため位相余裕が 18.7° まで減り，ランプ偏差にオーバーシュート・アンダーシュートが強く出ます．位相余裕が足りていれば， $T_1$ を指針より小さくして定常偏差の収束を早めてもよい，というのが講義の指摘です．

## 位相進み補償

```math
K_{lead}(s) = \frac{T_2 s + 1}{\beta T_2 s + 1} \quad (\beta < 1)
```

$1/T_2$ と $1/(\beta T_2)$ の間で位相が進み，最大進みは

```math
\omega_m = \frac{1}{T_2\sqrt{\beta}}, \qquad \phi_m = \sin^{-1}\frac{1 - \beta}{1 + \beta}, \qquad
\beta = \frac{1 - \sin\phi_m}{1 + \sin\phi_m}
```

です．高周波ゲインが $1/\beta$ 倍になるので $\omega_{gc}$ も上がります．低周波ゲインは変わらないので定常偏差は変わりません．

### 例 2：位相余裕を 60° にする

1. 補償前の位相余裕は 38.7°．目標 60° との差は 21.3° で，余裕をみて $\phi_m = 30°$ とする．
2. $\beta = (1 - \sin 30°)/(1 + \sin 30°) = 1/3$ ．
3. 補償後に $\omega_{gc}$ が $\omega_m$ に移ることを見込み， $\vert P(j\omega_m) \vert = \sqrt{\beta}$ となる $\omega_m = 2\sqrt{3} \approx 3.46$ を求める．
4. $T_2 = 1/(\omega_m\sqrt{\beta}) = 1/2$ ．

結果は $K_{lead}(s) = (1.5s + 3)/(0.5s + 3)$ で，シミュレータでは PM = 60.0° ， $\omega_{gc} = 3.46$ rad/s になります．「β, T2 を決める」ボタンで同じ手順を実行できます．

## 例 3：位相進み遅れ補償

位相進み補償で $\omega_{gc}$ 付近の位相余裕を確保しておくと，位相遅れ補償器の $T_1$ を 5 から 0.5 ( $\omega_{gc}$ 付近) まで下げても使えるようになり，定常偏差の収束が速くなります．プリセット「例 3」では補償なし，遅れのみ ( $T_1 = 5$ )，進みのみ，進み + 遅れ ( $T_1 = 0.5$ ) を比較します．ランプ偏差が $1/40$ に向かって速く収束する一方，位相余裕は約 33° になります．定常偏差・速応性・減衰性のバランスをボード線図と時間応答で確認してください．

## 結果欄の見方

| 項目 | 意味 |
|:--|:--|
| $\omega_{gc}$ ， PM， GM | 一巡伝達関数 $L = PK$ の交差角周波数と余裕 |
| $K_v$ | 速度定数 $\lim sL(s)$ (積分器 1 個のとき有限) |
| ランプ定常偏差 | $1/K_v$ |
| ステップ定常偏差 | $1/(1 + L(0))$ (積分器があれば 0) |
| $\omega_m$ ， $\phi_m$ | 各補償器の最大位相遅れ / 進みとその角周波数 |
| $1/T_1$ と $\omega_{gc}$ の比 | $\omega_{gc} T_1$ ．10 以上が設計指針 |

## パラメータ一覧

| パラメータ | 初期値 | 説明 |
|:--|:--|:--|
| 分子係数 / 分母係数 | `8` / `1 2 0` | $P(s) = 8/(s(s+2))$ |
| ゲイン $k$ | 1 | ゲイン補償 |
| $\alpha$ ， $T_1$ | 10, 5 | 位相遅れ補償 |
| $\beta$ ， $T_2$ | 1/3, 0.5 | 位相進み補償 |
| 遅れの比 | 10 | $1/T_1 = \omega_{gc}/10$ |
| $\phi_m$ | 30° | 位相進み補償の最大位相進み |
| 終了時刻 T | 10 s | 時間応答の計算 |
