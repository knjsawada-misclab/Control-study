制御工学 (応用理工学科機械工学科目3年) ／大阪大学 澤田賢治

アクティブ除振台を題材に，**モデルマッチング制御**をインタラクティブに体験するシミュレータです．PD 制御 (状態フィードバック) により閉ループ系の極を所望の位置に配置し，外乱に対する応答の概形を設計する過程をアニメーション・時間応答・極配置図で可視化します．

> **対象**：2次系の質量-ばね-ダンパ系に対して，PD 制御による極配置 (モデルマッチング) を体験的に学ぶシミュレータです．

付属の `model_matching_simulator.html` を **ブラウザで開くだけ**で動作します (外部ライブラリ不要・オフライン可)．

```bash

```

操作のポイント：

- **プリセット** で代表的なシナリオ (制御なし・各種応答速度の PD 制御) を一括設定．
- **物理パラメータ** (質量 $m$ , 減衰 $d$ , ばね定数 $k$ ) を編集．
- **目標極** $a$ を設定し，「PD ゲイン算出」で $c_p, c_d$ を自動計算．
- **外乱** をインパルスまたはステップから選択．
- **▶ 計算・シミュレーション** でシミュレーションを実行し，アニメーションを再生．

## アクティブ除振台

### 運動方程式

質量 $m$ がばね定数 $k$ と減衰係数 $d$ で支持された除振台の運動方程式は

```math
m\ddot{y}(t) + d\dot{y}(t) + ky(t) + u(t) = f(t)
```

ここで $y(t)$ は台の変位， $u(t)$ はアクチュエータ力 (制御入力)， $f(t)$ は外乱 (衝撃力) です．

### 状態方程式

状態 $x = [y, \dot{y}]^\top$ とすると，

```math
\dot{x} = \begin{bmatrix} 0 & 1 \\ -k/m & -d/m \end{bmatrix} x + \begin{bmatrix} 0 \\ -1/m \end{bmatrix} u + \begin{bmatrix} 0 \\ 1/m \end{bmatrix} f, \quad y = [1 \quad 0]\, x
```

## モデルマッチング制御

### 設計の考え方

外乱 $f(t)$ から出力 $y(t)$ への伝達関数 $G(s)$ の**極を所望の位置に配置**することで，応答の概形を設計します．

### PD 制御 (状態フィードバック)

```math
u(t) = c_p y(t) + c_d \dot{y}(t) = [c_p \quad c_d]\, x(t) = Kx(t)
```

閉ループ系の特性多項式は

```math
s^2 + \frac{d + c_d}{m} s + \frac{k + c_p}{m}
```

### 2重根への極配置

極を $s = -a$ の2重根に配置する場合，

```math
s^2 + \frac{d + c_d}{m} s + \frac{k + c_p}{m} = (s + a)^2
```

より，

```math
c_d = 2am - d, \quad c_p = a^2 m - k
```

このとき，インパルス応答は

```math
y(t) = \frac{1}{m} t\, e^{-at}
```

$a$ の値が大きいほどインパルス応答が速く減衰し，除振性能が向上します．

## プリセット例の解説

### 制御なし (受動系)

$u = 0$ の場合．ばねと減衰のみで外乱を吸収します．減衰比が小さいと振動が長く続きます．

### PD 制御 (各 $a$ の値)

| $a$ の値 | 応答特性 |
|---|---|
| $a = 0.5$ | 緩慢な応答，長い整定時間 |
| $a = 1$ | 臨界減衰に近い応答 |
| $a = 3$ | 高速応答 |
| $a = 5$ | 超高速応答，大きな制御入力が必要 |

$a$ を大きくすると応答は速くなりますが，制御ゲインも大きくなり，実際のアクチュエータでは制約となります．

## パラメータ一覧

### 入力パラメータ

| パラメータ | 説明 | 既定値 |
|---|---|---|
| $m$ | 質量 [kg] | $1$ |
| $d$ | 減衰係数 [Ns/m] | $0.5$ |
| $k$ | ばね定数 [N/m] | $4$ |
| $a$ | 目標極 (2重根 $s = -a$ ) | $1$ |
| $c_p$ | 比例ゲイン | 自動算出 |
| $c_d$ | 微分ゲイン | 自動算出 |
| 外乱 | インパルス / ステップ | インパルス |
| $T$ | シミュレーション時間 [s] | $10$ |

### 解析結果 (出力)

| 表示項目 | 説明 |
|---|---|
| 開ループ系 | $A$ の固有値と伝達関数 |
| 閉ループ系 | $A + BK$ の固有値と伝達関数 |
| フィードバックゲイン $K$ | $K = [c_p, c_d]$ |
| 安定性バッジ | 開ループ/閉ループの安定判定 |

### プロット

| プロット | 内容 |
|---|---|
| 除振台アニメーション | PD 制御あり (青) と制御なし (灰) を並列表示 |
| 時間応答 | $y(t)$ の比較 (PD 制御・制御なし・解析解) |
| 極・零点マップ | 開ループ極 (灰×)・閉ループ極 (青●)・目標極 (赤◎) |

### 数値計算手法

| 項目 | 手法 |
|---|---|
| 時間積分 | 4次 Runge-Kutta 法 (RK4) |
| ゲイン算出 | 特性多項式の係数比較 |
| アニメーション | requestAnimationFrame による描画 |
