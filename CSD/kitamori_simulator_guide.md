# 部分的モデルマッチング法 (北森法) シミュレータ

制御系設計論 (大学院 機械工学専攻) ／大阪大学 澤田賢治

講義「④ PID ゲインのチューニング」のうち，**部分的モデルマッチング法 (北森法)** を，ブラウザ上で手を動かして確認するシミュレータです．制御対象 $P(s)$ の分母系列展開 (マクローリン展開) を計算し， $1/G_{yr}(s)$ と規範モデル $1/M(s)$ の係数を低次から一致させて PID ゲインを決める手順を，係数比較表と応答の比較で追うことができます．

> **対象**：任意の伝達関数 $P(s) = b(s)/a(s)$ (係数入力)，規範モデル $M(s)$ (北森の規範モデル，2 項係数標準形，Butterworth 標準形，カスタム)，I-PD / I-P / PD 制御です．FRIT (データ駆動設計) は別のシミュレータ `frit_simulator.html` で扱います．

操作のポイント：

- **制御対象** は分子・分母の係数を高次から低次の順に空白区切りで入力します (例: `1 2` と `1 1 1` で $(s+2)/(s^2+s+1)$ )．
- **制御器の構造** で I-PD / I-P / PD を選び，**規範モデル** で北森の規範モデル，2 項係数標準形，Butterworth 標準形，カスタムを選びます．
- 「北森法でゲイン設計」を押すと，分母系列の係数 $\gamma_i$ ，設計したゲイン，閉ループ応答と規範応答の比較，**$1/G_{yr}(s)$ と $1/M(s)$ の係数比較表**，ゲイン線図が表示されます．
- **打ち切り次数 N** を変えると，分母系列を有限項で打ち切った $1/\gamma_N(s)$ のステップ応答が $P(s)$ とどれだけずれるかを確認できます (講義の「有限打ち切りの影響」)．

## 部分的モデルマッチング法 (北森法)

### 手順

制御対象 $P(s)$ と規範モデル $M(s)$ が与えられたとき，

1. 閉ループ伝達関数 $G_{yr}(s)$ を求める．
2. $1/G_{yr}(s)$ と $1/M(s)$ のマクローリン展開を計算し，低次の項から順に一致させて制御器のパラメータを決める．

### 分母系列表現

伝達関数は分母だけに多項式をもつ形 (分母系列表現) に展開できます．

```math
P(s) = \frac{b(s)}{a(s)} = \frac{1}{\gamma_0 + \gamma_1 s + \gamma_2 s^2 + \gamma_3 s^3 + \cdots}, \qquad
\gamma_k = \frac{1}{k!}\left.\frac{\mathrm{d}^k}{\mathrm{d}s^k}\frac{1}{P(s)}\right|_{s=0}
```

シミュレータでは微分を使わず，講義の問題 1 と同じ係数比較で求めています．すなわち $\gamma(s)\,b(s) = a(s)$ を低次から順に解きます．

```math
\gamma_k = \frac{1}{b_0}\left(a_k - \sum_{j=1}^{k} b_j \gamma_{k-j}\right)
```

ここで $a_k$ ， $b_k$ は $s^k$ の係数です．例えば $P(s) = (s+2)/(s^2+s+1)$ では $\gamma_0 = 1/2$ ， $\gamma_1 = 1/4$ ， $\gamma_2 = 3/8$ となります (問題 1)．

分母系列は低次の項が低周波特性，高次の項が高周波特性を表します．低次で打ち切ると減衰特性にその影響が現れます．

### I-PD 制御の設計 (問題 3)

I-PD 制御 $u = (k_I/s)\,e - (k_P + k_D s)\,y$ の閉ループ伝達関数の逆数は

```math
\frac{1}{G_{yr}(s)} = 1 + \frac{k_P}{k_I}s + \frac{k_D}{k_I}s^2 + \frac{1}{k_I}\frac{1}{P(s)}s
= 1 + \frac{k_P + \gamma_0}{k_I}s + \frac{k_D + \gamma_1}{k_I}s^2 + \frac{\gamma_2}{k_I}s^3 + \frac{\gamma_3}{k_I}s^4 + \cdots
```

となります．3 次の規範モデル $1/M(s) = 1 + m_1 s + m_2 s^2 + m_3 s^3$ と $s^3$ の項まで一致させると

```math
k_I = \frac{\gamma_2}{m_3}, \qquad k_P = k_I m_1 - \gamma_0, \qquad k_D = k_I m_2 - \gamma_1
```

です． $s^4$ 以上の項は一致しないので，これが閉ループ応答と規範応答の差 (主に減衰特性) として現れます．係数比較表ではこの一致・不一致を色分けしています．

### I-P 制御，PD 制御の設計

| 構造 | 一致させる次数 | 設計式 |
|:--|:--|:--|
| I-P: $u = (k_I/s)e - k_P y$ | $s^2$ まで | $k_I = \gamma_1 / m_2$ ， $k_P = k_I m_1 - \gamma_0$ |
| PD: $u = k_P e - k_D s\, y$ | $s^2$ まで | $k_P = \gamma_2 / m_2$ ， $k_D = k_P m_1 - \gamma_1$ |

PD 制御は積分器をもたないため，定常偏差を 0 にするには制御対象に積分器が必要です ( $\gamma_0 = 0$ )．問題 2 の $P(s) = b/(s(s+a))$ では $\gamma_1 = a/b$ ， $\gamma_2 = 1/b$ となり，2 次規範モデル $m_1 = 2\zeta/\omega_n$ ， $m_2 = 1/\omega_n^2$ に対して

```math
k_P = \frac{\omega_n^2}{b}, \qquad k_D = \frac{2\zeta\omega_n - a}{b}
```

が得られます．これは講義の解答と一致します．

### 規範モデル

| 名称 | 2 次 | 3 次 | 特徴 |
|:--|:--|:--|:--|
| 2 項係数標準形 | $\zeta = 1$ | $\alpha_1 = \alpha_2 = 3$ | 極が $s = -\omega_n$ の重根，オーバーシュートなし |
| Butterworth 標準形 | $\zeta = 1/\sqrt{2}$ | $\alpha_1 = \alpha_2 = 2$ | オーバーシュート 4.3 % (2 次)，8.2 % (3 次) |
| 北森の規範モデル | $1 + \sigma s + 0.5\sigma^2 s^2$ | $1 + \sigma s + 0.5\sigma^2 s^2 + 0.15\sigma^3 s^3$ | オーバーシュート約 10 %， $\sigma$ が小さいほど速い |

3 次の標準形は $1/M(s) = 1 + (\alpha_1/\omega_n)s + (\alpha_2/\omega_n^2)s^2 + s^3/\omega_n^3$ です．

---

## 数値計算の方法

- 時間応答は伝達関数を双一次変換 (Tustin 変換) で離散化し，IIR フィルタとして計算しています．
- 閉ループ極は Durand–Kerner 法で求め，安定性判定に使っています．
- 制御対象は分子次数 ≤ 分母次数の任意の伝達関数を受け付けます．
